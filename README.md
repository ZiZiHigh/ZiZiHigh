## About me

I like the practical side of IT: DNS, certificates, permissions, backups and
the moment when something that should work does not. I learn by running a
small Arch Linux homelab with Docker, nginx, Samba AD, monitoring and restic.
I keep notes on both the working setup and the failures, because that is where
most of the learning happens.

I am based in the Czech Republic and I am open to IT support and junior Linux
administration opportunities.

## Projects

### Homelab

A private Arch Linux server with pinned Compose projects, a single nginx
entry point, Samba AD, Prometheus and Grafana monitoring, and a daily restic
backup. The repository includes a build log, troubleshooting notes and the
parts that are still unfinished.

[Repository](https://github.com/ZiZiHigh/homelab)

### Homelab ticketing

osTicket on a private Arch homelab: digest-pinned Compose stack, internal
database network, nginx reverse proxy and a detailed failure log.

[Repository](https://github.com/ZiZiHigh/homelab-ticketing)
